Skill Gap Analysis

For the Data Analyst role specifically

Current Strengths You Already Have

Python MySQL / SQL Machine Learning (Research) Data Analysis (Academic) Big Data (IBM Certified) ETL Concepts (ERP/Portal Development) REST API & Backend Systems Stakeholder Communication Statistical Reasoning (Research Papers) Problem Solving (HackerRank 5★) Cloud Fundamentals (AWS, IBM Cloud)

Missing / Needs Development (Job Description Gaps)

Power BI Tableau Excel (Advanced — Pivot, VLOOKUP, Power Query) Dashboard Design & Reporting KPI Tracking Frameworks Formal Data Cleaning Pipelines

Recommended Learning Roadmap

  1. Power BI Fundamentals (Weeks 1–3)

    Microsoft Learn free path or Coursera's Power BI course. Focus on building dashboards from scratch using real datasets. Target: PL-300 certification.

  2. Advanced Excel for Data Analysis (Week 4)

    PivotTables, Power Query, VLOOKUP/XLOOKUP, and conditional formatting. Use ExcelJet or Chandoo.org tutorials — 1 hour/day for 7 days is sufficient.

  3. Pandas + Matplotlib / Seaborn in Python (Weeks 5–6)

    You already know Python — now add data analysis libraries. Build 2 portfolio projects: one with a CSV dataset, one with a SQL-connected dataset.

  4. SQL for Analytics (Week 7)

    Window functions, CTEs, GROUP BY analytics, subqueries. Use Mode Analytics SQL Tutorial or SQLZoo — practical, free, and fast.

  5. Tableau Public (Week 8)

    Build 1–2 published dashboards on Tableau Public using open datasets (India census, COVID, stock data). This gives you a portfolio link to share with recruiters.

  6. Kaggle Projects × 2 (Weeks 9–10)

    Complete 2 Kaggle notebooks end-to-end: EDA → visualization → insight summary. These become portfolio pieces demonstrating real data analyst workflow.
